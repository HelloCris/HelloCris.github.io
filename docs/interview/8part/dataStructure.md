# 数据结构

## 二叉树的四种遍历方式

二叉树的遍历（traversing binary tree）是指从根结点出发，按照某种次序依次访问二叉树中所有的结点，使得每个结点被访问依次且仅被访问一次。

| 遍历方式     | 访问顺序/规则                                                          |
| :----------- | :--------------------------------------------------------------------- |
| **前序遍历** | 先访问**根结点**，然后前序遍历**左子树**，再前序遍历**右子树**。       |
| **中序遍历** | 中序遍历根结点的**左子树**，然后是访问**根结点**，最后遍历**右子树**。 |
| **后序遍历** | 从左到右先叶子后结点的方式遍历访问**左右子树**，最后访问**根结点**。   |
| **层序遍历** | 从根结点从上往下逐层遍历，在同一层，按从左到右的顺序对结点逐个访问。   |

## 数组和链表的区别

> **核心结论**：数组是**连续内存** + **按下标随机访问**，适合"读多写少"的场景；链表是**分散内存** + **通过指针串起来**，适合"频繁插入/删除"的场景。两者在内存布局、访问方式、增删效率上完全相反。

| 对比维度      | 数组                         | 链表                               |
| :------------ | :--------------------------- | :--------------------------------- |
| **内存布局**  | **连续**内存空间             | **分散**内存，通过指针串联         |
| **访问方式**  | 支持**按下标随机访问**，O(1) | 只能**顺序遍历**，O(N)             |
| **插入/删除** | 需要**移动大量元素**，O(N)   | 只需**修改指针**，O(1)             |
| **空间开销**  | 仅存储数据，空间利用率高     | 每个节点需额外存储指针，有额外开销 |
| **扩容方式**  | 一般需**整体搬迁**到更大空间 | 按需创建新节点，天然支持动态扩展   |
| **适用场景**  | **读多写少**、频繁查询       | **频繁插入/删除**、写多读少        |
| **典型应用**  | 数组、动态数组、哈希表底层   | 链表、栈、队列、邻接表、LRU 缓存   |

## 算法的时间和空间复杂度

> **核心结论**：时间复杂度衡量"**跑得多快**"，空间复杂度衡量"**吃多少内存**"。我们用 **大 O 表示法** 描述它们随数据规模 `n` 增长的变化趋势，**忽略常数和低阶项**，只看最高阶。

::: info 时间复杂度（Time Complexity）

- **含义**：算法执行所耗费的时间，**随数据规模 `n` 的变化趋势**。
- 大 O 表示的是**最坏情况**下的渐进上界。

:::

::: info 空间复杂度（Space Complexity）

- **含义**：算法运行过程中**临时占用**的存储空间，随 `n` 的变化趋势。
- 包括：算法本身占的空间、输入数据的副本、额外申请的数组 / 哈希表 / 栈等。

:::

| 复杂度           | 名称     | 典型算法举例                     | 趋势感受           |
| ---------------- | -------- | -------------------------------- | ------------------ |
| **`O(1)`**       | 常数     | 哈希表查询、数组按下标访问       | 跟 `n` 无关        |
| **`O(log n)`**   | 对数     | 二分查找、平衡树操作             | 增长极慢           |
| **`O(n)`**       | 线性     | 顺序遍历、一次遍历数组           | 数据翻倍，时间翻倍 |
| **`O(n log n)`** | 线性对数 | 快排、归并排序、堆排序           | 主流排序算法的上限 |
| **`O(n²)`**      | 平方     | 冒泡 / 选择 / 插入排序、双层循环 | `n` 翻倍，时间 ×4  |
| **`O(2ⁿ)`**      | 指数     | 朴素斐波那契递归、子集枚举       | `n` 一变就爆炸     |
| **`O(n!)`**      | 阶乘     | 全排列（暴力）、旅行商 NP 问题   | 完全不可承受       |
