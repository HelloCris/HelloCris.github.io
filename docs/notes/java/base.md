# Java 基础入门与核心语法

## 语言总览

::: info 跨平台原理

- **核心机制**：Java 能够在不同的操作系统上运行，依赖于在操作系统上安装对应的 **Java 虚拟机**。
- **作用**：JVM 屏蔽了底层操作系统的差异，实现了“一次编写，到处运行”。

:::

::: info JRE 和 JDK

**JRE**

- **定义**：Java 程序运行时的环境。
- **组成**：包含 JVM 和需要的核心类库。
- **用途**：如果只需要运行一个已有的 Java 程序，只需安装 JRE 即可。

**JDK**

- **定义**：Java 程序开发工具包。
- **组成**：包含 JRE + 开发人员使用的工具。
- **关键工具**：编译工具 `javac.exe` 和运行工具 `java.exe`。
- **用途**：想要开发一个 Java 程序，必须安装 JDK。

:::

::: info Java 程序开发运行流程

1. 编写程序
   - 开发者编写源代码文件（`.java` 文件）。

2. 编译程序
   - 使用 `javac` 命令进行编译。
   - **产物**：得到字节码文件（`.class` 文件），这是与平台无关的中间代码。

3. 运行程序
   - 使用 `java` 命令启动 JVM 加载并执行字节码文件。

:::

## 基本概念

### 常量

**定义**：在程序运行中，其值不可发生改变的量。

| 常量类型       | 说明                 | 举例                        |
| :------------- | :------------------- | :-------------------------- |
| **字符串常量** | 用双引号括起来的内容 | `"HelloWorld"`, `"程序员"`  |
| **整数常量**   | 不带小数的数字       | `666`, `-88`                |
| **小数常量**   | 带小数的数字         | `13.14`, `-5.21`            |
| **字符常量**   | 用单引号括起来的内容 | `'A'`, `'0'`, `'我'`        |
| **布尔常量**   | 布尔值，表示真假     | 只有两个值：`true`, `false` |
| **空常量**     | 一个特殊的值，空值   | 值是：`null`                |

### 数据类型

Java 是强类型语言，每种数据都有明确的类型，占用不同的内存空间。

::: info 数据类型分类

- **基本数据类型**：
  - **数值型**：
    - 整数 (`byte`, `short`, `int`, `long`)
    - 浮点数 (`float`, `double`)
  - **非数值型**：
    - 字符 (`char`)
    - 布尔 (`boolean`)
- **引用数据类型**：
  - 类 (`class`)
  - 接口 (`interface`)
  - 数组 (`[]`)

:::

::: info 基本数据类型详情表

| 数据类型   | 关键字            | 内存占用 | 取值范围                                                                   |
| :--------- | :---------------- | :------- | :------------------------------------------------------------------------- |
| **整数**   | byte              | 1        | -128 ~ 127                                                                 |
|            | short             | 2        | -32768 ~ 32767                                                             |
|            | **int (默认)**    | 4        | -2的31次方到2的31次方-1                                                    |
|            | long              | 8        | -2的63次方到2的63次方-1                                                    |
| **浮点数** | float             | 4        | 负数: -3.402823E+38到-1.401298E-45; 正数: 1.401298E-45到3.402823E+38       |
|            | **double (默认)** | 8        | 负数: -1.797693E+308到-4.9000000E-324; 正数: 4.9000000E-324到1.797693E+308 |
| **字符**   | char              | 2        | 0-65535                                                                    |
| **布尔**   | boolean           | 1        | true, false                                                                |

:::

### 变量

- **概念**：内存中的一个存储区域（在程序运行过程中，其值可以发生改变）。
- **格式**：`数据类型 变量名 = 值;` （实例：`int a = 10;`）
- **注意事项**：
  - 在 Java 中，变量必须先定义后使用，仅定义不赋值的话使用会报错。
  - `Long` 型的结尾需要加 `L`。
  - 对于 `float` 类型，需要加上 `f` 后缀。

### 类型转换

**自动类型转换**

- **概念**：把更小的值赋值给一个数据范围大的变量。
- **示例**：`double a = 10;` （输出：10.0）

**强制类型转换**

- **概念**：把更大的值赋值给一个数据范围小的变量。
- **示例**：`int a = (short)10.1;` （输出：10）

**转换顺序图（从小到大）**

`byte` -> `short` -> `int` -> `long` -> `float` -> `double`  
_(注：`char` 也可以直接转换为 `int`)_

### 运算符

::: info 算术运算符

- **表达式**：用运算符把变量或常量连接起来复合 Java 语法的句子可称为表达式；`a+b` 就是表达式。
- **注意**：整数除法只能得到整数，要想得到浮点数，必须有浮点数的参与。

---

**字符 + 操作**

1. 字母和数字相加，字母会被转为数字。
   - eg: `System.out.println('a'+0);` 得到：97
2. 算术表达式里有多个不同基本类型值时，整个表达式的类型会自动提升。
   - eg: `double c=1.34+'c';` 这里 double 类型 + char 类型，char 被提升了
3. **提升规则**：
   - `byte`类型，`short`类型和`char`类型将被提升到`int`类型。
   - 整个表达式的类型自动提升到表达式中最高等级操作数同样的类型。
   - **等级顺序**：`byte, short, char` → `int` → `long` → `float` → `double`

---

**字符串 + 操作**

- 当操作中出现字符串时，`+` 是**连接符**，多个 `+` 操作时，从左到右执行。
- eg: `System.out.println("cyp"+100+99);` 结果：`cyp10099`
- `System.out.println(100+99+"cyp");` 结果：`199cyp`

:::

::: info 赋值运算符

- **注意**：小范围数值时 `+=` 这种运算符会进行强制转化。
- 示例：
  ```java
  int i=10;
  i+=9.9; // int i = i + 9.9
  System.out.println(i); // 结果：19 (int类型+=double类型，double被强制转换了)
  ```

:::

::: info 逻辑运算符

- **符号**：`!` `&` `|` `^`
- **短路逻辑运算符**：`&&` `||`

| 符号   | 作用   | 说明                           |
| :----- | :----- | :----------------------------- |
| `&&`   | 短路与 | 作用和`&`相同，但是有短路效果  |
| `\|\|` | 短路或 | 作用和`\|`相同，但是有短路效果 |

- **注意事项**：
  - 逻辑与 `&`：无论左边真假，右边都要执行。
  - 短路与 `&&`：如果左边为真，右边执行；**如果左边为假，右边不执行**。
  - 逻辑或 `|`：无论左边真假，右边都要执行。
  - 短路或 `||`：如果左边为假，右边执行；**如果左边为真，右边不执行**。

:::

### 基础输入与随机数

**数据输入 Scanner 类**

- **Scanner 类**：获取用户的输入。
- **引入后创建对象**：`Scanner sc = new Scanner(System.in);`
- **接收数据**（这一步就会让用户进行输入，输入完成后才对 x 赋值）：
  - `int x = sc.nextInt();`

**随机数 Random 类**

- **引入后创建对象**：`Random r = new Random();`
- **生产随机数**：
  - `int num = r.nextInt(10);`
  - **随机范围**：0 ~ 传入数值-1

## 数组

- **概念**：是一种用于存储多个**相同类型**数据的存储模型。
- **定义格式**：
  - **格式一**：`数据类型[] 变量名`
    - 范例：`int[] arr`
  - **格式二**：`数据类型 变量名[]`
    - 范例：`int arr[]`

### 数组初始化

**概念**：就是为数组元素分配内存空间，并为每个数组元素赋值。

1. 动态初始化

- **定义**：初始化时只指定数组长度，由系统分配初始值。
- **代码示例**：
  ```java
  int[] arr = new int[3];
  ```

2. 静态初始化

- **定义**：初始化时指定每个元素的具体值，长度由系统自动计算且不可变。
- **代码示例**：
  - **推荐写法**：
    ```java
    int[] arr2 = {4, 5, 6};
    ```
  - **完整写法**：
    ```java
    int[] arr = new int[]{1, 2, 3};
    ```

::: info 内存分配

Java 的内存主要分为栈内存和堆内存，它们在数组创建过程中扮演不同角色：

- **栈内存 (Stack)**：
  - 存放**局部变量**（即定义在 `main` 方法中的变量）。
  - 特点：用完立即消失。
  - 作用：存储变量名（如 `arr`）及其指向堆内存的**地址值**。
- **堆内存 (Heap)**：
  - 存放 `new` 出来的内存实体（对象）。
  - 特点：会有地址值，会把地址值赋给等号左边的变量。
  - 作用：存储数组的具体数据。
- **默认值机制**：
  - 数组初始化时，系统会对存储空间添加默认值（例如 `int` 类型的数组默认值为 `0`）。

:::

::: warning ⚠️ 注意

- **null (空值)**：这是引用数据类型的默认值。
- **含义**：表示该变量不指向任何对象（即没有地址值）。如果尝试访问 null 变量的属性或方法，会抛出空指针异常。

:::
