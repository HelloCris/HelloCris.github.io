# 面向对象编程

## 面向对象

### 类和对象

**对象**

- **概念**：世间万物客观存在的事物皆对象
- **对象有属性和行为**

**类**

- **概念**：类是对现实生活中一类具有共同属性和行为的抽象，用来确定对象将会有的属性和行为
- **类的重要性**：类是java程序的基本组成单位
- **类的组成**：类有属性和行为

```java
public class Phone {
    //成员变量
    String Brand;
    int price;
    //成员方法
    public void call(){
        System.out.println("打电话");
    }
    public void sendMessage(){
        System.out.println("发消息");
    }
}
```

> **类和对象关系**
>
> 类是对象的抽象，对象是类的实体。

### 成员变量和局部变量

- **定义**：成员变量是在类中方法外定义的变量，局部变量是在方法内定义的变量
- **区别**：

| 区别           | 成员变量                                   | 局部变量                                       |
| -------------- | ------------------------------------------ | ---------------------------------------------- |
| 类中位置不同   | 类中方法外                                 | 方法内或者方法声明上                           |
| 内存中位置不同 | 堆内存                                     | 栈内存                                         |
| 生命周期不同   | 随着对象的存在而存在，随着对象的消失而消失 | 随着方法的调用而存在，随着方法的调用完毕而消失 |
| 初始化值不同   | 有默认的初始化值                           | 没有默认的初始化值，必须先定义，赋值，才能使用 |

### 封装

::: info private 关键字

- 是一个权限修饰符，**修饰成员（成员变量和成员方法）**
- 作用是保护成员不被别的类直接使用，**被 private 修饰的成员只能在本类中使用**
  ```java
  private String name;
  ```
- 如果要在其他类中使用 private 修饰的变量，可提供 set get 方法，**这些方法不用 static**
  ```java
  public String getName() {
      return name;
  }
  public void setName(String name) {
      this.name = name;
  }
  ```
- **在其他类中使用**
  ```java
  // System.out.println(s.name); 错误不能被直接使用
  s.setName("cyp");      //设置了值
  System.out.println(s.getName()); //获取了值
  ```

:::

> this
>
> 方法被哪个对象调用，this 指向谁

::: info 总结

**封装概述**

- 是面向对象 3 大特征之一（封装、继承、多态）
- 是一个面向对象语言对客观世界的模拟，客观世界里的成员变量由隐藏在内部，外界无法直接操作

**封装原则**

- 将类的某些信息隐藏在类内部，不允许外部程序直接访问，而通过该类的方法来实现对隐藏信息的操作和访问
- 成员变量提供 getXxx setXxx 方法

**封装好处**

- 通过方法来操作变量，提高了代码安全性
- 代码用方法进行封装，提高了复用性

:::

### 构造方法

**概念：** **就是类 构造 对象时调用的方法**，主要时完成对象数据的初始化

**注意：**

- 如果没有定义构造方法，系统会定义一个默认的无参构造方法
- 构造方法可重载
- 如果给出了有参构造，就没有默认的无参构造

```java
public Student(){
}
public Student(String name,int age){
    this.name=name;   //在此方法中对数据进行初始化
    this.age=age;
}
```

## 继承

- **概述**：是面向对象3大特征之一，可以使得子类具有父类的属性和方法。
- `Father` 是父类，也被称为基类、超类。
- `Son` 是子类，也被称为派生类。
- 示例代码：`public class Son extends Father {}`

> **优缺点**
>
> 好处：提高了代码的复用性，维护性。  
> 坏处：是让类与类产生了联系，类的耦合增强。

### super

- `super`：代表父类存储空间的标识（父类对象的引用）。
- 可以通过 `super()` 调用父构造方法。

| 关键字    | 访问成员变量                     | 访问构造方法                 | 访问成员方法                          |
| :-------- | :------------------------------- | :--------------------------- | :------------------------------------ |
| **this**  | `this.成员变量`访问本类成员变量  | `this(...)`访问本类构造方法  | `this.成员方法(...)`访问本类成员方法  |
| **super** | `super.成员变量`访问父类成员变量 | `super(...)`访问父类构造方法 | `super.成员方法(...)`访问父类成员方法 |

### 继承中方法属性的访问特点

**构造方法的访问**

- **概述**：因为子类会继承父类的数据，所以子类在初始化之前，一定要先完成父类的初始化。
- 子类构造方法第一条默认语句都是 `super()`。

**成员变量的访问**

- 子类方法查找一个变量特点：局部查找，再子类成员查早，最后父类成员查找；也可通过 `this` 和 `super` 直接访问指定位置的变量。

**成员方法的访问**

- 子类对象访问一个方法：先在子类成员中查找，再在父类成员中查找。
- 子类方法中也可空过 `super.父方法()`，调用。
- `@Override`：是一个注解，检查重写方法的正确性。

**方法重写**

- **概念**：子类出现和父类一模一样的方法（名和参数）。
- **注意**：
  - 私有方法不能被继承也不能重写。
  - 子类方法访问权限不能更低 （public > 默认 > 私有）。

::: warning ⚠️ 注意
不能同时继承多个类，但是能多层继承。
:::

## 修饰符

### package概念

**package 包**

- 概述：Java 项目中一个包就是一个文件夹，对类进行分类管理。
- 定义格式：`package cyp.com;`
- **带包类的编译和执行**：
  1. 手动建包：把普通编译后的文件放到对应的文件夹（包）下，执行就是 `javac 包.类名`。
  2. 自动建包：编译：`javac -d . java名`。

**import 导包**

- 概述：使用不同包下的类时要写全，导包后就简化了。
- 格式：`import pa.get.Test;` (pa.get 包下的 Test 类)

### 权限修饰符

| 修饰符        | 同一个类中 | 同一个包中子类无关类 | 不同包的子类 | 不同包的无关类 |
| :------------ | :--------: | :------------------: | :----------: | :------------: |
| **private**   |     √      |                      |              |                |
| **默认**      |     √      |          √           |              |                |
| **protected** |     √      |          √           |      √       |                |
| **public**    |     √      |          √           |      √       |       √        |

### 状态修饰符

**final (最终态)**
可修饰成员方法、成员变量，类，局部变量。

- 用 final 修饰成员方法后不能被子类重写（不是重载）。
- 成员变量不能被赋值。
- 类不能被继承。
- 修饰局部变量基本类型不能被赋值，引用类型地址不能变，但内容能变。

**static**
是静态的意思，可修饰成员方法和成员变量。
**static 修饰特点：**

- 被类的所有对象共享，修改变量所有的对象都受到影响。
- 能被类直接调用。
- 静态方法只能访问静态方法和属性，非静态方法能访问静态和非静态方法、属性。

## 多态

概述：同一对象在不同时刻展现出来的不同形态

::: info 多态的前提和体现

- 有继承关系
- 有重写方法
- 有父引用指向子对象

:::

::: info 多态中成员访问特点

- 访问成员变量时，访问的是父中变量，子没有则报错
- 访问成员方法时，主要也是父中方法，如果子类重写了方法，访问的是子类中的方法；如果父中没有方法，不能直接访问子类方法

:::

::: info 多态的优缺点

- 优：提高了程序的扩展性
- 缺：不能使用子类的特有方法

:::

::: info 多态转型

- 向上转型：子→父，父类引用指向子对象
- 向下转型：父→子，父类引用转为子类对象

```java
//向上转型，子->父，父类引用指向子类对象
Person s1=new Son();
s1.eat();

//向下转型，父->子，父类引用转为子对象
Son s2=(Son)s1;
s2.eat();
s2.special();
```

:::

## 抽象类

概述：抽象类是一个不具体的类，不能描述出一个完整对象，java 中没有方法体的方法就是抽象方法，有抽象方法的类就是抽象类

```java
public abstract class ObstractC {
    public abstract void fn();
}
```

::: info 抽象类特点

1. 抽象类抽象方法必须使用 `abstract` 关键字修饰类和方法
2. 有抽象方法的类一定是抽象类；但抽象类里可以没有抽象方法
3. **抽象类不能实例化，只能通过多态的方式使用**
4. 抽象的子类，要么重写抽象方法，要么也是抽象类
5. 抽象类中成员特点：可以有成员变量、常量，有构造方法，有抽象和非抽象方法

:::

## 接口

**概述**：接口就是一种公共规范标准，只要符合规范标准，大家可以通用；java 中接口更多体现在对行为的抽象。

::: info 接口特点

1.  接口用关键字 `interface` 修饰
    `public interface Jumping {...}`
2.  类实现接口用 `implements` （类实现接口就像类继承类）
    `public class JumpDemo implements Jumping{...} //JumpDemo实现Jumping`
3.  接口不能直接实例化，参照多态方式
4.  接口实现类（相当于继承的子类），要么重写接口中所有方法，要么是抽象类

:::

::: info 接口成员特点

1.  **成员变量**：只能是常量，接口中成员变量有默认修饰符 `public static final`
2.  **构造方法**：**接口没有构造方法**，因为接口主要对行为进行抽象，没有具体存在
3.  如果一个类没有父类，默认继承 Object 类
4.  **成员方法**：只能是抽象方法，默认修饰符 `public abstract`

:::
::: info 接口和类的关系

1.  **接口和类**：实现关系，类可以实现多个接口
2.  **接口和接口**：继承关系，可单继承也可多继承
3.  **接口和抽象类的理念区别**：
    - 抽象类对类抽象，包括属性、行为
    - 接口对行为抽象，主要是行为

:::
::: info 各种 类 作为形参和返回值

- **普通类**
  需要或返回的是类的对象
- **抽象类**
  需要或返回的是该抽象类的子对象
- **接口**
  需要或返回的是接口的实现类对象

:::

::: info JAVA8 后接口新增特性

- **默认方法**：接口中加上 `default` 关键字的方法，可以有方法体，可以调用，也可以被重写
- **静态方法**：接口中加上 `static` 关键字的方法，可以有方法体，只能被本接口调用
- **私有方法**：java9 的新特性，加上 `private` 的方法

:::

## 内部类

**内部类**：就是在一个类中定义一个类。

**内部类的访问特点**

- 内部类可直接访问外部类的成员
- 外部类访问内部类必须先创建对象

**内部类分类**

- 在类的成员位置：**成员内部类**
- 在类的局部位置：**局部内部类**（方法内定义的类）

**匿名内部类**

- **前提**：要存在一个类或接口
- **本质**：是一个继承了该类或实现了该接口的**子类匿名对象**
- **格式** (要在方法中定义):

```java
new 类名(){
    重写方法;
}
```
